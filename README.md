# insurance_analytics_excel_dashboard
"An Excel project that cleans and analyses insurance data (customers, policies, claims and payments), answers 21 business KPIs using pivot tables and a Data Model, and presents the results on an interactive dashboard with KPI cards, charts and slicers.”
Insurance Policy Analysis Dashboard

Objective: Turn raw insurance data into clear insights through an Excel dashboard that answers 21 key business questions.

Data: 5 sheets with 5,000 records each (Customer Information, Policy Details, Claims, Payment History, Additional Fields), linked by Customer ID and Policy ID.

What I did:

Cleaned the data and converted each sheet to an Excel Table
Added helper columns (Age Group, Start Year, End Year, Active/Inactive)
Built a Data Model linking the tables
Created pivot tables for each KPI
Built a dashboard with KPI cards, charts and slicers

Key insights:

5,000 customers and 5,000 policies, with 251.4M in total claims
Only 33.64% of policies are active (about 1 active for every 2 inactive)
Health is the largest policy type and Auto the smallest
Average premium is falling by about 1.9% a year
Policy endings peak in 2025

Tools: Microsoft Excel (Tables, Pivot Tables, Data Model, Slicers, formulas)

Files: Policy Data.xlsx (data and dashboard)
